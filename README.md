## 골프 스코어 & 게임 계산기

라운드 중 폰으로 스코어를 입력하면 개인 성적과 여러 내기 게임의 승패·금액이 즉시 계산되고, 마지막에 누가 누구에게 얼마를 보내면 되는지 최소 송금 횟수로 정리해 줍니다. 설치나 서버 없이 브라우저만 있으면 되고, 한 번 열어두면 오프라인에서도 동작합니다.

### 지원 게임

| 게임 | 방식 | 정산 |
|---|---|---|
| 스트로크 플레이 | 그로스/네트(핸디 적용) 순위 | (선택) 타수 차 × 단가, 전원 1:1 |
| 스테이블포드 | 홀별 점수 합산 (버디 3 · 파 2 · 보기 1 · 이글 4) | 순위만 |
| 스킨스 | 개인 또는 팀(베스트볼), 동타 시 캐리오버 | 스킨당 단가 |
| 매치 플레이 | 개인은 전원 리그전, 팀은 2팀 베스트볼 | 종료 시 홀 차 × 단가 (예: 3&2 → 3홀 차) |
| 나소 | 전반 9 / 후반 9 / 전체 18 세 판의 매치 | 판당 단가 |
| 베스트볼 (팀) | 홀마다 팀원 중 베스트 1개 또는 베스트 2개 합 | 홀 승리당 단가 |
| 라스베가스 (2:2) | 두 명 점수를 낮은수·높은수로 붙여 비교 (4·5 → 45), 상대 버디면 뒤집힘 | 점수 차 × 단가 |
| 보너스 | 니어리스트, 롱기스트, 버디(이글 2배) | 1회당 다른 플레이어 각각 지급 |

- 플레이어 2~8명, 팀은 A~D 4팀까지. 핸디캡은 홀별 핸디캡 인덱스에 따라 자동 분배되며 게임마다 네트 적용 여부를 선택할 수 있습니다.
- 9홀/18홀, 홀별 파·핸디캡 인덱스는 입력 중에도 수정 가능합니다.
- 라운드 중에도 게임이나 금액을 바꿀 수 있고 결과는 즉시 다시 계산됩니다.
- 정산 탭에서 개인별 손익, 게임별 내역, 최소 송금 목록을 보여주고 텍스트로 복사/공유할 수 있습니다.
- 데이터는 기기 브라우저(localStorage)에만 저장되며, 종료한 라운드는 기록으로 남습니다.

### 사용 방법

1. `golf-score/index.html`을 브라우저로 열거나, GitHub Pages 주소로 접속합니다.
2. 폰에서는 "홈 화면에 추가"를 하면 앱처럼 전체 화면으로 쓸 수 있습니다.
3. 새 라운드 → 플레이어·팀·게임 선택 → 라운드 시작 → 홀마다 스코어 입력 → 리더보드/정산 확인.

로컬에서 서버로 띄워 보려면:

```bash
cd golf-score
npm start        # http://localhost:8787
npm test         # 게임 계산 로직 단위 테스트 (node --test)
```

### GitHub Pages 배포

`.github/workflows/pages.yml`이 `main` 브랜치에 푸시될 때 테스트를 돌린 뒤 저장소 전체를 GitHub Pages로 배포합니다.
저장소 Settings → Pages → Source를 **GitHub Actions**로 한 번만 설정하면 됩니다.
배포 후 주소는 `https://<계정>.github.io/<저장소>/golf-score/` 입니다.
