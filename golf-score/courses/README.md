# 코스 폴더

이 폴더에 들어 있는 코스 파일이 앱의 **골프장 받기** 목록에 나옵니다.
파일을 넣으면 목록에 생기고, 지우면 목록에서 빠집니다. 목록 파일(`index.json`)은 배포할 때 자동으로 만들어지므로 손댈 필요가 없습니다.

## 골프장을 목록에 추가하는 방법

### 방법 1. 정밀 약도까지 넣고 싶을 때

골프장 안내도(PDF나 이미지)를 Claude 대화에 올리고 "이 골프장 추가해줘"라고 요청합니다.
코스 파일을 만들어 이 폴더에 넣고 배포합니다.

### 방법 2. 직접 올릴 때

1. 앱에서 새 라운드를 만들 때 **코스** 칸에 골프장·코스 이름을 적습니다. ("라운드 / 골프장 이름" 칸이 아니라 그 아래의 "코스" 칸입니다. 여기에 이름이 없으면 코스가 저장되지 않습니다.)
   홀마다 파·거리·위험 요소·키워드를 입력하고 라운드를 마치면, 그 이름으로 코스가 폰에 저장됩니다.
   (다른 사람이 보내 준 코스 파일을 받아도 됩니다.)
2. 앱 홈의 **골프장 받기 · 코스 보내기**에서 그 코스의 **보내기**를 눌러 파일로 저장합니다.
3. GitHub에서 이 폴더(`golf-score/courses`)를 열고 **Add file → Upload files**를 눌러 파일을 끌어다 놓은 뒤 **Commit changes**를 누릅니다.
4. 1~2분 뒤 자동으로 배포되고, 앱의 목록에 나타납니다. (이미 앱을 열어 둔 폰은 목록 화면에서 "새로 고침"을 누르면 보입니다.)

## 알아 둘 점

- 파일 이름은 자유롭게 정해도 됩니다. 다만 `.json`으로 끝나야 하고 `/ \ ? # %`는 쓸 수 없습니다. `index.json`은 목록 파일의 이름이라 쓸 수 없고, 점(`.`)으로 시작하는 이름과 폴더 안에 넣은 파일은 읽지 않습니다.
- 내용이 올바르지 않은 파일, 이름이나 자리가 맞지 않는 파일은 목록에 넣지 않고 건너뜁니다. 올렸는데 목록에 안 나오면 GitHub의 **Actions** 탭에서 최근 배포의 "Build the course list" 단계를 보면 파일마다 이유가 적혀 있습니다(`SKIPPED 파일 이름: 이유`).
- 같은 골프장(이름과 홀 수가 같은 것)의 파일이 여러 개면 파일 안의 `updated` 날짜가 가장 늦은 것 하나만 목록에 나옵니다.
- 코스를 고쳐서 다시 올릴 때는 **같은 파일 이름으로 덮어쓰거나, 예전 파일을 지우고** 올립니다. 내용이 달라졌으면 목록에서 이미 받은 사람에게 "새로 받기"가 뜹니다(같은 날 고쳐 올려도 됩니다). 앱에서 보내기로 만든 파일에는 만든 날짜(`updated`)가 들어 있는데, 이 날짜가 예전 파일보다 앞서지만 않으면 됩니다.
  - 예전 파일을 그대로 두고 다른 이름으로 올리면 같은 골프장의 파일이 둘이 되어, 날짜가 같을 때 어느 쪽이 목록에 나올지 알 수 없습니다.
  - 코스 파일을 목록이 아니라 메신저로 따로 받은 사람에게는, 목록의 날짜가 그 사람이 가진 것보다 늦을 때만 "새로 받기"가 뜹니다.
- 앱에 기본으로 들어 있는 두 코스(베어크리크 포천의 베어·크리크)도 본보기로 이 폴더에 들어 있습니다. 앱에 이미 들어 있어서 목록에는 "기본 포함"으로만 보이므로, 이 두 파일은 지워도 됩니다. (`tools/export-builtin-courses.js`가 만든 파일입니다.)
- 이 폴더의 파일을 지우거나 바꾸거나 잘못된 파일을 올려도 앱 배포는 멈추지 않습니다. 목록에 나올 수 없는 파일만 건너뜁니다.

## 코스 파일의 모양

```json
{
  "format": "golf-score-course",
  "v": 1,
  "name": "골프장 · 코스 이름",
  "holes": 18,
  "pars": [4, 4, 3, 5, "…"],
  "strokeIndex": [7, 3, 15, 1, "…"],
  "holeInfo": { "0": { "dist": 362, "shape": "L", "haz": 227, "memo": "키워드 · 키워드" } },
  "map": ["(선택) 홀마다 약도 자료. golf-score/coursemaps.js와 같은 모양"],
  "note": "(선택) 설명",
  "updated": "2026-11-12"
}
```

안내도 이미지는 넣지 않습니다. 약도는 홀의 윤곽을 단순하게 옮겨 그린 좌표입니다.
